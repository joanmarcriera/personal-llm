# Domain Notes

These files are the curated, human-written layer that explains how you think across your main work domains.

Use them for:

- stable opinions and default approaches
- tradeoff preferences
- heuristics you want the model to reuse
- examples of what you consider a good answer in your own work

## How to use them

1. Start with [../persona.md](../persona.md) so the model's tone and working style are explicit.
2. Add or refine domain files with your real defaults, not generic summaries.
3. Convert the best parts into SFT examples using [../../docs/10_dataset_design_examples.md](../../docs/10_dataset_design_examples.md).
4. Record important revisions in [../snapshots/README.md](../snapshots/README.md) when they affect training or evaluation.

If you are unsure where a piece of knowledge belongs, use [../../docs/11_personal_knowledge.md](../../docs/11_personal_knowledge.md) and [../../docs/13_data_quality.md](../../docs/13_data_quality.md).
